# 试用准备视图（TrialWorkspace）

一句话：把“对话模型、开发执行、当前项目/会话、可用入口”放在一页，只给四个导航动作，不新增权限。

## 1. 入口与读取时机

- 左侧（手机为底部）导航中的 **试用准备** 打开本视图；默认仍是主对话。
- 只有会话已建立、且你打开该视图时，页面才读取 `GET /v1/readiness`；关闭视图不轮询。
- 每次重新打开读取一次；右上角刷新会再次读取试用状态，并让工作台刷新配置。都只读，不发命令、不调用模型。
- 本页没有项目选择、会话创建、批准、恢复授权或自动接受；这些仍走原有页面。

## 2. 顶部状态条

三格，一行一句话：

| 格 | 可能的值 | 含义 |
| --- | --- | --- |
| 运行模式 | 个人模式 / 产品模式 / 固定流程 | 本次启动的类型；固定流程是受控测试通路 |
| 对话模型 | 已配置 / 未配置 / 服务异常 / 未知 | 只描述对话模型配置与 provider 状态 |
| 开发执行 | 配置已具备 / 需要项目 / 暂不可用（原因）/ 固定流程 / 只读恢复 / 未知 | 只描述配置与观察到的可用性 |

每一格都是“颜色圆点 + 文字”，不靠颜色单独表达状态。

**必须记住的翻译：**

- “配置已具备”≠ 已连接、已测试、已授权。页面固定加注“配置事实，非连接验证”。
- “固定流程”= 不会运行原生 Codex。
- “未知”= 没有观察到，不是正常。
- “只读恢复”= 可以审阅，不能派工、批准或恢复授权。
- “暂不可用”后面的文字就是真实原因（未安装、版本不匹配、需要认证、开发执行已关闭等）。

## 3. 当前项目与会话

- “当前项目”显示左侧筛选选中的项目；筛选为“全部项目”时显示“全部项目”。
- “当前对话”显示你正在使用的会话标题。
- 项目列表显示名称、开发/讨论、是否可派工、绑定执行器数量；当前项目标记“当前”。**项目行是只读事实，不是选择器**，切换项目仍用左侧既有筛选。

## 4. 下一步与动作

只提供四个导航动作：

| 按钮 | 打开什么 | 注意事项 |
| --- | --- | --- |
| 配置对话模型 | 原有模型设置面板 | 打开≠发送模型请求 |
| 导入项目 | 原有项目导入表单 | 只读恢复或后端未提供导入时不出现/明确拒绝 |
| 检查执行器 | 原有“执行器连接”视图 | 展示准入与阻塞原因，不启动执行 |
| 打开主对话 | 原有主对话视图 | 保留当前项目、会话与未发送草稿 |

主动作由当前缺口决定：模型未配置/服务异常 → 配置模型；执行不可用/未知 → 检查执行器；需要项目 → 导入项目；其余 → 打开主对话。其余动作最多两个。快速双击同一动作只算一次导航。

## 5. 加载、刷新、错误

- 第一次读取：显示“正在读取试用状态…”，三格为“未观察”。
- 刷新：保留上次结果，显示“正在刷新…”；刷新控件在读取期间保持可聚焦，但不会重复触发。
- 读取失败：红色提示条 + “重试”；下方仍显示上次结果并注明时间。重试不会清空对话、重复提交命令或发送模型请求。
- 服务没有该接口（旧版本）：显示“未提供试用状态接口”，既有视图继续可用；不会把旧观察当作当前服务状态。
- 迟到的旧响应不会覆盖新状态；切换后端/会话身份后旧数据立即隐藏。

## 6. 只读恢复

- 状态条显示“只读恢复”，顶部说明可以审阅历史。
- 只有“打开主对话”和“检查执行器”等只读入口；不出现导入、批准、恢复授权、重发或自动接受。
- 从其它入口尝试导入时，会显示“恢复数据只读，暂不支持导入项目”，不会创建项目。

## 7. 可选的配方草案（J 声明）

默认产品尚未接入项目声明草案；接入后，本页会在下方显示“配方草案”，它只是只读预览：

- 每行显示声明标题、状态（草案/需要输入/不支持）、目标预览、检查与执行器匹配数。
- 缺少项目根目录、当前配置未注册检查、执行器未准入或不属于当前项目时，会逐条说明并禁用“准备草案”。
- 点击“准备草案”只把草案数据交给原委托表单；是否创建、用哪些检查、是否执行仍由你在原确认页决定。这里不运行脚本、不装依赖、不注册检查。
- 加载失败会明确提示，原表单和主对话仍可使用；不会显示上一项目的旧草案。

## 8. 可选的使用观察

默认产品当前**不显示**观察区：G 的统计范围/覆盖仍在修复，main 没有传入指标。

只有 main 接入一份明确声明了**项目范围、观察窗口和覆盖范围**的可信摘要时，页面才展示：

- 观测范围、来源/聚合方式、未知数量、窗口与覆盖；
- 每行一个指标，保留单位/币种/层（界面观察、受控流程、原生执行、人工输入），不合计不同币种或层；
- `null` 显示“未知”，不填 0；样本不足只显示“样本不足”，不编造百分比。

摘要缺少范围/窗口/覆盖、范围不包含当前项目、或声明被截断却又称“complete”时，会明确说明原因，而不是显示一份看似完整的数字。来源已知/未知数量、窗口与覆盖会与摘要一起显示；`null` 保持未知，不同币种与层不合计。观察不构成授权、质量证明或自动接受条件。

## 9. 键盘与屏幕阅读器

- Tab 顺序：刷新 → 主动作 → 次动作；没有额外可聚焦元素。
- 焦点始终可见；状态更新不抢焦点；读取期间刷新控件保持焦点。
- 区域由标题命名；加载/刷新/接口缺失为 `status`，错误为 `alert`；图标按钮都有中文名称。
- 手机 390px：状态条改为三行，动作换行但仍可点击；页面无横向滚动。
