# 试用准备视图（TrialWorkspace）

一句话：把“对话模型、开发执行、项目、入口”四件事实放在一页，只给四个导航动作，不给新的权限。

## 1. 现在在哪里

组件位于 `apps/console/src/trial/`，数据来自 main 已发布的 `GET /v1/readiness`（`TrialReadinessSchema`）和现有 `ApplicationConfiguration`。

- **main 尚未把视图接进 App**：页面导航里暂时看不到它。接入方式见 `reports/trial-experience/main-integration.zh-CN.md`。
- 接入后它只是工作台里的一个视图，不替换主对话，也不改变任何已有授权/确认流程。
- 接入前的开发预览（受控数据，不是产品入口）：
  ```sh
  cd apps/console
  node e2e/trial/trial-states.mjs
  node e2e/trial/trial-http.mjs
  ```

## 2. 顶部状态条

三格，一行一句话：

| 格 | 可能的值 | 含义 |
| --- | --- | --- |
| 运行模式 | 个人模式 / 产品模式 / 固定流程 | 本次启动的类型；固定流程是受控测试通路 |
| 对话模型 | 已配置 / 未配置 / 服务异常 / 未知 | 只描述对话模型配置与 provider 状态 |
| 开发执行 | 配置已具备 / 需要项目 / 暂不可用（原因）/ 固定流程 / 只读恢复 / 未知 | 只描述配置与观察到的可用性 |

每一格都是“颜色圆点 + 文字”，不靠颜色单独表达状态。

**必须记住的翻译：**

- “配置已具备”≠ 已连接、已测试、已授权。页面固定加注“配置事实，非连接验证”。
- “固定流程”= 不会运行原生 Codex。
- “未知”= 没有观察到，不是正常。
- “只读恢复”= 可以审阅，不能派工、批准或恢复授权。

## 3. 下一步与动作

页面只提供四个导航动作，不会自己发请求或执行命令：

| 按钮 | 打开什么 | 注意事项 |
| --- | --- | --- |
| 配置对话模型 | 原有模型设置面板 | 打开≠发送模型请求 |
| 导入项目 | 原有项目导入表单 | 只读恢复下不出现（导入是写入） |
| 检查执行器 | 原有“执行器连接”视图 | 展示准入与阻塞原因，不启动执行 |
| 打开主对话 | 原有主对话视图 | 不改变当前项目/会话选择 |

主动作由当前缺口决定：模型未配置/服务异常 → 配置模型；执行不可用/未知 → 检查执行器；需要项目 → 导入项目；其余 → 打开主对话。其余动作最多两个，作为次要入口。

快速双击同一动作只算一次导航（300ms 内的重复回调被忽略）。

## 4. 项目与执行器明细

- **项目**：显示名称、开发/讨论、是否可派工、绑定了几个执行器；当前项目标记“当前”。行是只读的。
- **执行器与能力**：原生/固定流程数量与已准入数量；上下文历史、来源审阅、项目决定、提案的入口是否已在配置中提供。
- 页脚固定显示：只读配置观察、未授予执行权限、不含项目路径/凭据/模型端点，以及配置 revision 前 8 位。

## 5. 加载、刷新、错误

- 第一次读取：显示“正在读取试用状态…”，三格为“未观察”。
- 刷新（右上角刷新按钮）：保留上次结果，显示“正在刷新…”。
- 读取失败：红色提示条 + “重试”；下方仍显示上次结果并注明时间。重试只重新读取状态，不会清空对话、重复提交命令或发送模型请求。
- 服务没有该接口（旧版本）：显示“未提供试用状态接口”，既有视图继续可用。
- 迟到的旧响应不会覆盖新状态。

## 6. 只读恢复

- 状态条显示“只读恢复”，顶部说明可以审阅历史。
- 只有“打开主对话”和“检查执行器”等只读入口；不出现导入、批准、恢复授权、重发或自动接受。
- 已读内容与你刚才在对话/审阅中看到的一致；不要把只读当作“等一会儿就会自动解锁”。

## 7. 可选的使用观察

如果 main/G 提供了可信摘要，页面底部会出现“使用观察”：

- 显示窗口、样本数、覆盖范围与已知限制。
- 样本不足时只显示“样本不足，暂不展示效率结论”，不填 0、不编百分比。
- 未知指标显示“未知”。
- 观察只是参考，不构成授权、质量证明或自动接受条件。

## 8. 键盘与屏幕阅读器

- Tab 顺序：标题区刷新 → 主动作 → 次动作 → 项目/执行器明细中的链接（无额外可聚焦元素）。
- 焦点始终可见（2px 青绿轮廓）；状态更新不抢焦点。
- 区域由标题命名；加载/刷新为 `status`，错误为 `alert`；图标按钮都有中文名称。
- 手机 390px：状态条改为三行，动作换行但仍可点击；页面无横向滚动。
