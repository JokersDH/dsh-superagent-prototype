# 内部试用指南

版本：wave-25（2026-11-14）· 适用对象：在本机试用“个人 Agent 工作台”的同事。

本指南只描述**当前仓库真实可用的东西**。计划中的桌面壳、云端多用户、第二/第三种真实执行器和自动接受都没有实现；看到“计划/未测”时不要当成功能。

## 入口

从仓库根目录启动：

```sh
pnpm install --frozen-lockfile   # 首次，或依赖变化后
pnpm start                        # 启动本机工作台；终端会打印实际地址（默认 5180，API 8796）
pnpm doctor                       # 启动异常时先诊断
pnpm stop                         # 停止本次启动的实例
```

`pnpm start` 会复用已经记录的同状态实例；若想用独立数据目录，显式给 `--state`、`--port`、`--api-port`（例如 `pnpm start --state .local-state/my-trial --port 5192 --api-port 8808`）。不要为了“干净”删除别人的 `.local-state` 或正在使用的凭据。

三种明确的启动方式：

| 命令 | 含义 | 会不会运行原生执行器 |
| --- | --- | --- |
| `pnpm start` | 个人启动；按本机已识别/已准入的配置工作 | 只有已准入的原生 profile 才可能派工 |
| `pnpm start --discussion-only` | 只允许普通对话与审阅；开发执行关闭 | 不会 |
| `pnpm start --fixture` | 固定流程测试通路，用于界面/流程验证 | 不会调用 Codex；不是原生能力证明 |

恢复只读（`recovery_readonly`）由恢复流程显式进入，不是普通开关；只读时不能派工、批准或恢复授权。

安装、升级、迁移与卸载属于分发指南（由交付包随附）；本仓库不提供第二套安装命令，也不承诺共享多用户服务。

| 能力 | 状态 |
| --- | --- |
| 主对话（流式回复、Markdown、会话草稿） | 已实现 |

| 上下文历史与原始来源审阅 | 已实现（审计说明输入，不证明模型正确性） |
| 提案/决定 | 已实现，需显式确认；不自动执行 |
| “试用准备”视图 | 已接入真实 App 导航（main a302）；按认证+可见性读取只读状态，见 [试用准备](03-trial-readiness.zh-CN.md) |
| 使用观察（效率报告） | 可选输入与准入校验已留出；G 的完整指标尚未准入，默认产品不显示观察区 |

真实原生范围目前是 macOS arm64 + Codex 0.164.0 的一个受控范围；其他平台/版本显示为未准入。固定流程不是原生准入，界面上会明确写“固定流程/非原生执行器”。

## 安全边界（请先读）

- 普通对话不会授权编码；执行只来自你明确确认的委托。
- 页面上的“已配置/配置已具备”是配置事实，不是连接已验证、执行已授权或发布已通过。
- 不要在对话、截图或工单里粘贴 `bootstrap.key`、`api.key`、模型 key、原生 profile 或数据库文件。
- 试用数据留在你自己的状态目录；不要复制他人的 `.local-state`、`codex`/原生 profile 或数据库。
- 出现“未知”时不要当作成功，也不要反复提交同一命令；按 [问题处理](04-troubleshooting.zh-CN.md) 保留现场再重试。
