# 个人 Agent 助理：简介与使用指南

这是一个本机优先的开发助理工作台，把讨论、工作委托、人工确认和验证交付放在同一个入口。网页关闭后，本机服务仍可保留工作；记录和产物保存在自己的电脑上。

当前版本已接入真实大模型对话，工作执行仍是固定 scratch 的受控验证。它还不是能自由修改任意仓库的通用编码 Agent。

## 现在可以做什么

| 功能 | 当前状态 | 适合做什么 |
| --- | --- | --- |
| 大模型主对话 | 可用 | 讨论需求、拆解开发计划、比较方案、解释粘贴的代码、整理内容 |
| Markdown 回复 | 可用 | 阅读列表、表格和代码块；外部图片不会自动加载 |
| 独立对话与记录 | 可用 | 新建对话，刷新后保留当前对话；浏览器后退可以回到前一个对话 |
| 模型切换 | 可用 | 在“模型设置”中选择本机已配置的模型 |
| 工作委托、原生提问 | 受控验证 | 测试任务如何进入工作台、如何把子进程问题交给你回答 |
| 检查与人工接受 | 受控验证 | 检查通过后接受当前候选；失败不能被人工确认覆盖 |
| 产物预览、下载 | 受控验证 | 查看交付清单、patch、输出文件和检查证据 |
| 暂停、停止、修订、重试 | 按当前工作动作提供 | 测试版本切换和停止状态；状态未知不会假装已安全停止 |
| Codex / ZCode / DeepSeek Harness 自动改代码 | 尚未开放 | 等独立运行时、权限、恢复及真实执行器验收完成后接入 |
| 自动学习、跨 harness 子团队 | 后续方向 | 当前不把这些设计能力当作已实现功能 |

## 一分钟开始

1. 双击仓库根目录的 `start.command`，或在仓库运行 `pnpm start`。
2. 打开 `http://127.0.0.1:5180`。本机试用无需登录令牌。
3. 点击“新对话”，输入一个具体问题，例如：

   > 我想做一个个人项目的需求管理工具，请把第一版拆成可独立验收的开发任务，并指出风险。

4. 回复由真实模型生成并持久保存，刷新页面仍可查看。
5. 顶部模型名称或设置图标可以打开“模型设置”。

选中工作只用于查看详情。输入框的“主对话”会与模型讨论；明确选择“当前工作”才会把消息补充到所选工作。模型回复本身不会创建、停止或验收工作。

## 如何验证工作流程

点击工作空间旁的加号“新建委托”。当前可选执行器都是受控验证 profile：

- **权限提问**：子进程提出一次允许/拒绝问题，回答后写入固定输出并运行检查。
- **检查通过**：直接生成正确的固定输出，供查看候选与接受交付。
- **检查失败**：生成不符合要求的输出，验证失败时不应出现接受入口。
- **延时任务**：延迟写入，适合测试暂停、停止和页面刷新。

检查通过后，在工作详情查看产物，再点击“接受当前候选”。不要把“收到模型回复”“进程退出”或“本地记录了回答”当作已经完成交付。真实完成由当前候选、检查结果和人工接受共同决定。

这些 profile 不会执行你在目标文本里要求的任意操作，不会修改你的生产仓库。它们用于确认协调和交互链路是否正确。

## 模型配置与数据范围

当前网关支持已配置的 GLM-5.3、GLM-5.3-Flash 和 DeepSeek-V4.1-Flash-1017。最后一个是该网关 `/models` 实际返回的 ID，与最初写法略有差别。

密钥只保存在本机私有文件 `~/.config/superagent-personal/model.json`，文件权限为 600，不在仓库、Git 或前端包里。页面只显示是否已配置，不返回密钥。更换网关或密钥时修改这个私有文件；正常模型切换可直接使用工作台设置。

当前 Base URL 使用 HTTP，传输不加密。模型请求只使用当前对话、当前项目的有限文本上下文，不自动读取或上传仓库文件。不要在对话里粘贴账号密钥。默认最多取 20 条上下文、总计约 24000 字符，单次输出上限由私有配置控制。

请求失败或结果提交不确定时，不会自动重复计费请求。页面会保留消息并显示通知，你可以明确重新发送。

## 启动、停止与测试

```sh
pnpm start      # 自动构建并启动；已有实例则复用
pnpm stop       # 停止本工作台，保留状态和产物
pnpm restart    # 后端代码或私有配置变化后重启
```

`stop.command` 也可用于停止。修改界面时 Vite 会热更新；后端改动需要重启。不要在浏览器验收过程中同时重建依赖模块，以免热刷新打断页面选择。

现在的重点是让你能稳定体验真实对话和可靠工作流，再逐步接入通过验收的编码执行器。页面上的“已交付”只描述对应受控工作的验收结果，不代表已经完成目标中的任意真实开发需求。
