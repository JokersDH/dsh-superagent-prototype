## 实施步骤

1. 实现可信 executable/argv 身份、版本和配置引用检查；发现检查不运行模型任务、不读取私有 token。
2. 能力分 advertised/observed/test/policy，分别呈现安装/认证/兼容/任务可用，required features 不静默豁免。
3. 经 Driver 事实映射原生权限，准备记录绑定 attempt/epoch/fingerprint，验证通过后才允许 begin。
4. 配置/HMR/二进制替换使旧记录失效；给出原生登录与专用 home bootstrap 步骤，不覆盖用户设置。
