## 实施步骤

1. 保留用户原工作区/dirty diff，以受控 worktree 和资源归属建立 attempt 目录；记录共享 git 元数据限制。
2. 绑定当前 candidateGeneration，确认 writer 静止后冻结 artifact 和环境；验证期间输入变化令候选失效。
3. 执行经批准的项目检查，记录真实 exit/outcome、criteria/environment/artifact digest；不信任 worker 自述。
4. 只输出可信 CompletionProposal，由应用/core gate 核对；测试 SKIPPED、人工条件、过期接受、集成失败和 GC 引用。
